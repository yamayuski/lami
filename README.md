# lami
lami CLI - Next-generation of git

## Development

This project includes a DevContainer configuration for easy development setup with VS Code.

### Quick Start with DevContainer

1. Open this repository in VS Code
2. Install the [Remote - Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)
3. When prompted, click "Reopen in Container"
4. Wait for the automatic setup to complete

The DevContainer includes:
- **Zig compiler** and language server
- **Node.js** for AI CLI tools (Gemini, Claude)
- **VS Code extensions** including GitHub Copilot and Zig support
- **Development tools** for building and debugging

For more details, see [`.devcontainer/README.md`](.devcontainer/README.md)
