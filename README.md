# lami
lami CLI - Next-generation of git

## Development Setup

For the easiest development experience, use the provided DevContainer:

1. Open this repository in VS Code
2. Install the Dev Containers extension if you haven't already
3. Click "Reopen in Container" when prompted
4. Wait for the initial setup to complete (15-30 minutes)

The DevContainer includes:
- Zig compiler (latest master via zig-bootstrap)
- Node.js LTS (22) with Gemini CLI
- Pre-configured VS Code extensions

For detailed setup instructions, see [DEVCONTAINER.md](DEVCONTAINER.md).
